VIDEOJUEGO SWEET CRUSH

Objetivo del videojuego:

Generar combinaciones de 3 o mas fichas contiguas iguales
junto a cascadas en donde se recolectaran puntos, entre mas
puntos mejor sera el rendimiento en partida.

Acciones:

    - Quitar ficha: seleccionas la ubicacion de la ficha a quitar,
    todas las fichas que esten arriba caeran y se generara fichas
    aleatorias en los espacios.
    
    - Quitar ficha/columna: seleccionas la fila o columnas que
    quieras quitar, el tablero se redimensiona juntando las dos
    partes divididas pudiendo generarse combinaciones.
    
    - Agregar ficha/columna: seleccionas a continuacion de que
    fila o columna quieres agregar la fila o columna, en esta 
    nueva fila o columna se generara aleatoriamente nuevas
    fichas sin generar una caida. nota: si quieres generar una
    fila o columa antes de la primera fila o columna se debera
    digitar '0'.
    
Terminos importantes:

    - Combinacion: 3 o mas del mismo tipo de ficha ubicados contiguamente
    en horizontaal o vertical, el producto de este generara la
    eliminacion de las fichas y luego unaa caaidaa de fichas.
    
    - Caida de fichas: se le denominaa al desplazamiento hacia
    abajo en posiciones de las fichas producido por la eliminacion
    de una ficha o producto de una combinacion.

    - Cascadas: Despues de hacer una accion y de que se generara
    una combinacion puede que se generen mas combinaciones producto
    de caida de fichas, a esto se le denomina cascadas. Se mostrara
    el tablero actualizado una vez hayan terminado las cascadas.
